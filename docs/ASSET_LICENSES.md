# Asset- und Lizenzvermerk – Akte Midas

## Aktuell eingebundene Grafiken

Der aktuelle Build verwendet ausschließlich eigens für dieses Repository erstellte SVG- und CSS-Grafiken:

- Midas-Siegel
- operative Silhouetten
- Aktenraster und Sicherheitslinien
- Zieloptik der Ermittlerrolle
- Dossier-, Stempel- und Auszählungseffekte

Diese Elemente werden direkt in `app/demo/AkteMidasApp.tsx` und `app/demo/akte-midas.module.css` erzeugt. Es wurden keine fremden Bilddateien oder Schriftdateien in das Repository übernommen.
